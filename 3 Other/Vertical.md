Планы для вертикального развития игры

Персонаж:
- Атрибуты персонажа. Базовые и получаемы от уровня.
- Таланты персонажа. Получаемые эффекты от параметров.

Оружие:
- Пассивные навыки от владения каждым оружием.
- Активные навыки каждого оружия. Анимации и характеристики.

Ремесло:
- Пассивные навыки каждой профессии (лесоруб, кузнец и т.д.)
- Оружия (кузнец)
- Доспехи (кузнец)
- Украшения (кузнец)
- Гемы (зачарование, ассеты и атрибуты каждого гема)
- Предметы для зачарование (придумать названия категории)

- Промежуточные ресурсы (брусья, слитки и прочее)
	1. Ресурсы для изготовления экипировки
	2. Ресурсы для изготовлени гемов
	3. Ресурсы для изготовления мебели
	4. Ресурсы для улучшения зданий
	5. Ресурсы для предметов улучшения экипировки 
- Мебель (изготовление)
- Зелья (алхимия)
- Еда (кулинария)
- Корма (кулинария)
- Удобрения (алхимия и кулинария)
- Ассеты огородничества 
- Ассеты животноводства
- Ассеты дереводобычи
- Ассеты шахтера
- Ассеты сборщика
- Рыба

- Инструменты
- Расходумеые предметы улучшения и поддержки экипировки:
	1. Улучшения уровня экипировки
	2. Улучшения грейда экипировки
	3. Увеличения прогресса уровня экипировки
	4. Увеличения прогресса грейда экипировки
	5. Улучшения грейда гемов
	6. Увеличения прогресса грейда гемов
	7. Ресурс для починки прочности
	8. Ресурс для перезарядки гемов
	9. Ресурс для подзарядки особых свойств

Улучшение предметов
- Базовые свойства
- Свойсва префиксы
- Свойства суффиксы
- Особые свойства

Строительство
- Постройки 
- Уровни улучшения
- Пассивные бонусы от строений

Гильдия
- Ресурсы для улучшения гильдийных зданий
- Ресурсы для производства осадных сооружений
- Реликвии и части (ассеты и бонусы)
- Осадные сооружения

Исследования
- Ветви иследования - боевые, ремесленные, другие
- Исследование - эффекты и бонусы.

Мир
- Королевства
- Города
- Локации для фарма монстров - споты
- Локации для фарма ресурсов  - леса, шахты, охотничьи угодья, озера и реки

Таблицы данных:
- DT_Character_Level - необходимый опыт персонажа для каждого уровня, а так же количество очков параметров и атрибутов за уровень 
- DT_Character_Talents - таланты параметров получаемые от уровня параметра
- DT_Character_Weapon_Level - необходимый опыт оружия для каждого уровня, а так же получаемый бонус к урону навыков 
- DT_Character_Weapon_Skillpoints - необходимый опыт для получения скиллпоинта для навыков оружий
- DT_Character_Profession_Level -  необходимый опыт для получения каждого уровня профессии, а так же бонусы к эффективности профессии
- DT_Character_Profession_Skillpoints  - необходимый опыт для получения скиллпоинта для навыков профессий
- DT_Equipment_Main_Stats - базовые атрибуты каждого ассета экипировки
- DT_Equipment_Prefics_Stats - возможные атрибуты префиксы для каждого типа экипировки и типа оружия
- DT_Equipment_Suffics_Stats - возможные атрибуты суффиксы для каждого типа экипировки и типа оружия
- DT_Gem_Stats - атрибуты гема на каждый грейд и очки зачарования
- DT_Item_Assets - сводная таблица по всем ассетам предметов
