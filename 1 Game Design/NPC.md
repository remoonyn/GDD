Основные цели НПС:
1. Наполнения мира для ощущения наполнености игры
2. Диалоги для погружения в лор игры
3. Торговля предметами с НПС
4. Квесты 

Наполнение
- НПС Стоят, бродят по миру, разговаривают друг с другом, взаимодествуют с окружением.
- Игроки при приближении к НПС активируют скрипт случайных диалогов
- НПС могут быть разного пола, расы, возраста.

Диалоги
- При взаимодействие с НПС открывается окно диалога, с помощью которого можно пообщаться с НПС
- У каждого НПС свой набор возможных уникальных диалогов
- Уникальный диалог начинается с фразы игрока, затем идет ответ НПС, после чего последующие варианты диалогов
ветвятся, для текущего уникального диалога, по окончанию диалога возвращается стартовое окно диалог, а диалог 
помечается серым цветом, как уже проговоренный.
- Под диалогом подразумевается полный диалог с 1-й по последнюю реплику. Соответсвенно условия завершения диалога - окончание последней реплики. 


Торговля
- При нажатии кнопки "Торговать" в диалоге, открывается окно торговли
- Каждый НПС торговец торгует только своим ассортиментом товаром

Квесты
- В окне диалога с НПС, если у него есть доступные квесты для взятия, разговора по квесту или завершению, появляется соответсвующая кнопка диалога

Структура реплик для таблицы DT_Line <- ST_Line
Row Name - Индекс реплики
- Index_Speaker - int32 (Индекс 0 - игрок, остальные это НПС)
- Line_Button - FText (Краткий текст будущего диалога для отображения в кнопке)
- Line_Dialogue - FText (Полный текст диалога)
- Audio_Dialogue - SoftObject (мягкая сылка на аудио файл озвучки полного диалога)
- Next_Line - int32 (Индекс следующей реплики)
- Reply_Player - TArray (int32) (Массив возможных реплик для ответа игроком)
- Index_Quest - int32 (Индекс квеста)
- Type_Quest - Enum (Тип логики реплики: None/Accept/Progress/Complete)

Структура НПС для DT_NPC <-ST_NPC
Row Name - Индекс НПС
- Name_NPC
- Index_First_Line - int32 (индекс для таблицы DT_Line)
- Quests_Availble
- Quest_Progress 
- Quest_Complete
- Quest? - bool (Бывают ли у НПС квесты?)
- Trader? - bool (Торговец ли НПС?)
- Trader_Type E_Trader_Type -  (Тип торговца, определяет ассортимент и какие предметы он покупает)
	- None
	- Weapon
	- Armor
	- Jewelry
	- Achemy
	- etc.
- TArray "int32" - Trader_Assortment (Массив ID предметов)

Структура квестов:
- Quest_Name - FText
- Quest_Description - FText
- Quest_Target - struct
- Quest_Bounty - struct
- Quest_Conditions_Level - int32 (Минимальный уровень персонажа)
- Quest_Conditions_Complete - int32 (индекс квеста)
- Quest_Type (сюжетный, побочный, повторяемый и т.д.)
