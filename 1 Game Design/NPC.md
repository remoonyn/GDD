Основные цели существования НПС:
1. Наполнения мира для ощущения не пустого игрового мира
2. Диалоги для погружения в лор игры
3. Торговля предметами с НПС
4. Квесты

Наполнение
- НПС Стоят, бродят по миру, разговаривают друг с другом, взаимодествуют с окружением.
- Игроки при приближении к НПС активируют скрипт случайных диалогов
- НПС могут быть разного пола, расы, возраста.

Диалоги
- При взаимодействие с НПС открывается окно диалога, с помощью которого можно пообщаться с НПС
- У каждого НПС свой набор возможных уникальных диалогов
- Уникальный диалог начинается с фразы игрока, затем идет ответ НПС, после чего последующие варианты диалогов ветвятся, для текущего уникального диалога, по окончанию диалога
