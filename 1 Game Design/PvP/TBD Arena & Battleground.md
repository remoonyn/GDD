### Arena
Формат боев:
- Бои 1х1 до 2 побед
- Командные бои 3х3 и 5х5 до 2 побед.
- Случайный подбор для рейтинга и партийный для тренировок. 
- Рейтинговые бои проводятся каждый день с 18:00 по 00:00. По выходным с 12:00 по 00:00.
- Характеристики персонажей ограниченны

Лига арены:
- Ежемесячное обновление рейтинга
- Получения наград в зависимости от максимально занимаемой позиции в рейтинге в какой либо категории.
- Независимо от количество категорий, награда получается только по одной максимально занимаемой.
- Цвет никнейма меняется в зависимости от позиции и категории в рейтинге и действует до следующего обновления рейтинга

Категории рейтингов:
- Количество убийств "Лучший убийца"
- Количество выигранных боев "Лучший игрок"
- Количество боев "Любитель сражений"
- Среднее MvP значение ассистов/баффов/хила "Лучший саппорт"
- Среднее MvP значение по урону/убийствам/ассистам "Мастер игры"


### Battleground
Формат боев:
- Бои 10х10 в режиме захвата "флага"
- Удержание флагов, длительность одного боя 10м.
- Выигрывает, тот кто получил больше очков
- Рейтинговые бои проводятся каждый день с 10:00 по 02:00.
- Характеристики персонажей не ограниченны
