
*Численной ограничение на количество смертей в ходе проведения всех осад с захватов городов/столиц*

- Базовое количество "подкреплений" для нападающих во время осады города - 500 человек.
- Базовое количество "подкреплений" для нападающих во время осады столицы - 2500 человек.
- Базовое количество "подкреплений" для защищающихся во время осады города на "последнем" этапе обороны - 50 человек.
- Базовое количество "подкреплений" для защищающихся во время осады столицы на "последнем" этапе обороны - 250 человек.
- Количество "подкреплений" в качестве нападающих и "защищающихся" можно увеличить, с помощью улучшения определенных "городских/столичных" сооружений

Примечания:
1. В ходе тестов определить возможные источники увеличения/восстановления подкреплений на осале
