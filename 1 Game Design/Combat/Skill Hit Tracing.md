Типы навыков по "области применения"

Для каждого из навыков применяется свой вариант трассировки попаданий, где исходные параметры для расчетов хранятся в навыке и делятся на определеные типы
Параметры (S_Skill_Trace_Parameters):

1. Type Trace (enum) Линейеная, сферическая
2. Type Trace Shape (enum) Тип формы трассировки 
3. Iinstantaneous (bool)
True - Мгновенная трасссировка сферой
False - Сфера движется/увеличивается со временем
4. Charging(bool)
True - Навык перед тем как вызвать трассировку, требует время на подготовку (зажатие клавиши, пример навык на Shift+LBM может от длительности зажатия LBM нанести пропорционально больше урона, от времени зажатия)
False - Мгновенной использование навыка
5. Charge Retention (bool)
True - Навык удерживается и не применяется по окончанию времени заряда
False - Навык по окончанию времени заряда срабатывает автоматически
6. Time Trace (float) Время для перемещения/увеличения/изменения сферы
7. Time Charging (float) Время максимального эффектка заряда, после 
8. MaxTargets (integer)
9. Radius (float)
10. Distance (float)

Капсульные (Capsule Collision)
- К режущей или ударной части оружия крепиться "капсула" по форме части оружия и при пересечения во время атаки с "капсулой" врага засчитывается попадание. (Пример: примерно так как работает оружие в Souls-like играх, где попаданием считается визуально касание оружием тела врага)

Линейные (Line Trace)
- Одиночные линейные удары (трассировки линии, точечные удары  перед собой в цель. Пример: выпад рапирой перед собой порожает одну цель в которую попал Line Trace)
- Одиночные летящие снаряды (летящий снаряд, при поподании в одну цель. Пример: стрела выпущенная из лука; магический НЕ пронзающий снаряд/луч)


Сферические (Sphere Trace)
- Круговые (Центр - персонаж, угол 360) используется для навыков с применением по области, где для каждой цели в которую попал trace засчитывается поподание навыком. Пример: бафф союзников, огненная волна наносящая урон, круговой удар двуручным мечом). 
- Угловые (Центр - персонаж, радиус переменный от 270 до 15 градусов) используются для навыков перед собой. Пример: размашистые удары и магические заклинания
- Заряжающиеся - навыки которые, предварительно заряжаются, где от длительности заряда зависит и эффект навыка (Shape - капсула перед собой, увеличивающийся от времени заряда)


Преследующие 
- Магические снаряды, которые преследуют цель автоматически. Сначала происходит регистрация большой сферой/, а затем в цель летит снаряд с определенной скоростью и временем существования, при поподании может быть или одиночным поподанием или вызывать Sphere Trace для регистрации массового поподания по врагам/союзникам

Указательные
- При нажатие комбинации клавиш, вызывается интерактивный виджет прицеливания навыком, позволяющий указать зону для применения навыка.
Пример №1: Персонаж использует комбинацию S+Q, где он подпрыгывает в воздух, и в моменте когда персонаж зависает в воздухе у игрока появляется возможность (к примеру в течении 1 секунды) указать область куда он приземлится и нанесет урон и допустим при нажатии LBM можно раньше вызвать анимацию приземелния
Пример №2: Персонажа использует комбинацию Shift+Q, и у персонажа появляется интерфейс, не ограниченный во времени, где он может указать область для вызыва эффекта навыка (к примеру массовое лечение или огненный дождь).
