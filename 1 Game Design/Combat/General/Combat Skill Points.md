- Боевые очки навыков (далее CSP) служат для изучения навыков и улучшения изученных в книге навыков нажатием ЛКМ на желаемый навык
- Для получения одного CSP необходимо убивать существ получая опыт за каждое убийство
- При получении определенного количества опыта персонаж получает 1 CSP. 
- Стоимость каждого нового CSP растет нелинейно, согласно концепции [[Diminishing Returns]]
- Каждое существо имеет свое базовое значения опыта при убийстве
- Итоговое количество получаемого опыта за каждое существо зависит различных факторов: 
- Для всех оружий общий прогресс в полученний CSP
- Максимальное количество CSP ограничено количеством в примерно равным количеству очков необходимых для полного изучения всех навыков на максимум для 3-4 видов оружия
- Каждый навык требует свое количество очков для изучения и улучшения
- Сбрасывать очки навыков можно с помощью специального итема и золота в книге умений клавишей ПКМ на навык
