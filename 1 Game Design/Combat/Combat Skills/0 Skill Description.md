Навыки:
- У каждого оружия по умолчанию есть базовый набор навыков - стартовые
- Новые навыки открываются по мере повышения уровня владения оружием
- Навыки можно улучшать в книги умений
- Количество подряд используемых навыков перемещения (перекаты, телепорты, отпрыгивания, чарджи) ограничены выносливостью и перезарядками
- Количество используемых мощных атакующих навыков подряд ограничено магической энергией и/или перезарядкой
- Спам хилящих умений ограничен перезарядкой/маной
- Спам баффов ограничен перезарядкой/маной и длительностью баффов
- ~~Прокачка навыков (новые вариации) представлены древом для каждого умения. Feature~~
- Навыки имеет свой уровень улучшения от 0 до 5
- На прокачку "уровня" навыка тратяться "очки навыков"
- Очки навыков получается во время охоты на монстров (фарме спотов)
- Очки навыков являются общими для всех оружий
- Очки навыков ограничены в количестве требуемом для максимальной прокачки всех навыков в игре
- При этом динамика прокачки навыков регулируется в процентном соотношении от уже полученных, таким первые навыки получаются быстрее, но дальше прогрессия замедляется с каждым полученным навыков, при обновлении игры и добавлении новых навыков, получению текщуего количества очков навыков упрощается
- Чем выше уровень умения (от 0 до 5), тем выше его характеристики, до х1.05 - х1.25 от эффективности 0 уровня (урон, перезарядка, длительность, расход ресурса)
- Количество одновременно используемых активных навыков ограничено только возможными комбинациями клавиш, порядка 30 навыков на 1 оружие. Благодаря системе динамической смены оружия, количество возможных навыков расширяется до 30х3 + базовый набор навыков движения (уклонения, прыжки, смещения)
