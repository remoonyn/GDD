Система состоит из следующих компонентов (Containers): 
1) Рюкзак  (100 слотов)
2) Премиум (безлимит)
3) Экипировка (15 слотов)
4) Сундук (200 слотов)
5) Хотбар (10 слотов)
6) Склад гильдии (общий)
7) Склад гильдии (ремесленный)
8) Склад гильдии (амбар)
9) Склад гильдии (сокровищница)
10) Лошадь (10 слотов, повышенная грузоподъемность)
11) Мастер зелье
12) Комплексный обед
13) Торговец - Ассортимент (свой базовый ассортимент товаром)
14) Торговец - Товары (бесконечный массив опредленной категории товаров, которые продают игроки)
15) ==Обмен - расширяющийся инвентарь обмена предметами между игроками==
16) ==Телега (фургон) - используется для перевозки между городами==

- Контейнер служит для хранения предметов и взаимодействия с ними
- Контейнер состоит из ячеек
- Для каждого из компонентов своя логика взаимодействия
