
- Компонент с массивом до максимального количества элементов - 100 шт.
- Базовое количество разблокированных слотов - 20 шт.
- В случае смерти, у игрока из инвентаря выпадает определенное количество тех или иных предметов предусмотренных штрафом за смерть в ПК
- У инвентаря есть свой максимальный вес, который можно увеличить с помощью предметов из игрового магазины
- В инвентаре присутствует кнопка для удаления предметов из инвентаря

Примечания:
1. В ходе тестов установить оптимальное количество слотов по умолчанию и максимальное
2. В ходе тестов установить оптимальный способ разблокировки новых слотов в соотношении время/деньги
3. Определить в ходе тестов необходимость веса/слотов
