
Торговец
- Для различных категорий предметов существуют отдельные торговцы
- Представляет собой бесконечный массив, куда можно перенести предметы из инвентаря для дальнейшей продажи
- Перенос предмета возможен drag & drop или double click LBM
- Изначально состоит из одной пустой ячейки (контейнер для drag & drop) 
- При переносе предмета в трейд, появляется ячейка с этим предметом
- Проданные предметы перемещаются на вкладку "Купить"
- Для каждого основных типов предмета есть свои типы торговцев
