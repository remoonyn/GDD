Квесты:
- В игре предусмотрено разделение квестов по категорями
	- Сюжетные [желто-оранжевый цвет]
		- Общий прогресс для всего аккаунта
		- Выполняются разово
		- Служат для погружения в историю мира игры
	- Второстепенные [светло-синий цвет]
		- Общий прогресс для всего аккаунта
		- Выполняются разово
		- Служат для погружения в историю мира игры
	- Ежедневные [зеленый цвет]
		- Отрываются после выполнения соответсвующего второстепенного квеста
	- Еженедельные [зеленый цвет]
		- Отрываются после выполнения соответсвующего второстепенного квеста
	- Ремесленные [зеленый цвет]
		- Повторяемые вариации ежедневных и еженеделньых квестов с ремесленными задачами
	- Гильдийные [красный цвет]
		- Случайны задания для каждой гильдии отдельно, с частой например каждый 4 часа новая партия
	- Специальные [фиолетовый цвет]
		- Особые задания. Резервная категория под квесты вне других категорий.
- Для каждой категории свои иконки и цвет названия квеста
- Для разовых и повторяемых квестов разные вкладки в окне заданий
- Для гильдийных квестов существует отдельная вкладка в виджете гильдии

Концепт взятия квестов:

Игрок берет квесты только у НПС. Для того чтобы у НПС была возможность активации диалога на взятие квеста, должны быть выполнены условия. Наличие квеста у НПС визуально никак не помечается, только через диалог.

При взятие квеста в журнале появляется запись о наличи квеста и полное его описание.
Для каждого типа квеста своя логика обработки. При этом обработка события для выолнения квеста срабатывает при наличии хотя бы одного квеста с конкретным типом квеста. К примеру: если игрока есть квест на убийство 10 кабанов, то у него активируется флаг QuestKill и при каждом убийстве любого монстра делается проверка на то тот ли монстр убит для квеста (по тэгу монстра). Для квестов с достижение цели, обработка и выполнение активируется при пересечении тригера. В котором есть проверка на то выполнил ли этот квест игрок ранее или нет. Для разговором с НПС, логика такая, что опция разговора на тему квеста у НПС появляется только при наличи квеста.
Для квестов с требованием наличия предметов (ресурсов) проверка происходит только при попытки сдать квест, динамически информация о наличии имеющихся ресурсов не отображается иначи при каждом получения и удалении предмета необхожимо будут выполнять кучу лишних операции, а для ММО это недопустимо.

Для квестов с требование квестового предмета, информация о статусе обновляется при получении предмета. Но возможность получения предмета появляется только при наличии квеста. Квестовые предметы возможно получить только при выполнение соответсвующего квеста. Квестовые предметы представлены отдельные от обычных предметов Data Assets и отдельным PrimaryDataAssets

При выполнение квеста. Квест перемещается во вкладку выполненых в журнале. И помечается соответсвующе. 
При этом квесты повторяемые поподают в отдельную категорию во вкладке выполненых и исчезают от туда при сбросе. Игрок получает награду в инвентарь. При нехватке места - квест нельзя закрыть и игрок получает соответсвующее предупреждение.

Примечание: квестовые предметы отличаются от обычных, они не занимают места в обычном инвентаре, а существуют только в виде массива внутри персонажа. Дабы не забивать игроку инвентарь не нужными вещами и не отвелекать его вопросами - "А зачем мне вообще нужна эта чаша?" или "А что это за древний меч? Может его выкинуть? А нельзя, жаль!"
