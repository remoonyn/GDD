Получение очков навыков оружия "Profession Skill Points"
- При убийстве любом крафте дается опыт в общий прогресс получение очков професии
- За очки прокачиваются навыки профессий

Получение очков навыков оружия "Weapon Skill Points"
- При убийстве монстра любым оружием вы получаете опыт в прогресс получения очков навыков 
- Очки нужны для того чтобы изучать новые навыки
- За каждый уровень дается одно очко навыков
- Требуемое количество опыта на каждое "очко навыков" одинаковое до определенного количества очков навыков 
- Каждое оружие вмещается в себя до 50% очков навыков от количества очков требуемых на изучение всех навыков конкретного оружия

Добыча золота:
- Золото в игре добывается различными способами
- Золото привязано к персонажу и храниться только в нем
- Золото необходимо для улучшений в различных игровых элементах, таких как улучшение экипировки и улучшение сооружений в городах
- Золото необходимо для покупки различных вещей на аукционе
- Основным источников добычи золота является сбор трофеев с убитых монстров с целью продажи их торговцу
- Основным источником расходов у игрока являются покупка расходуемых предметов для повышения характеристик и ремонт снаряжения и комиссии

Увеличение опыта владения ремесленными "Профессиями"
- При занятии ремеслом персонаж получает опыт профессии
- При повышении уровня профессии у персонажа открываются новые рецепты для производства и увеличивается эффективность добычи ресурсов
- Максимальный уровень в каждой ремесленной профессии ограничен
- При достижение максимального уровня профессии открывается система совершенствования "Парагон" 
- Система "Парагон" общая для всех ремесленных проффессий

Увеличение опыта владения "Оружием"
- При сражении определенным оружием игрок получает опыт владения используемым оружием
- Опыт начисляется с каждым ударом и зависит от используемго навыка
- Максимальный уровень владения оружием ограничен
- С увеличение уровня владения оружием, незначительно увеличивается весь урон наносимый данным оружием
- На определенных уровнях открываются новые навыки оружия
- При достижении максимального уровня владения оружием у персонажа разблокируется система совершенствования "Парагон"
- Система "Парагон" для оружий является общей для всех видов оружий, а не для каждого оружия в отдельности

Увеличение уровня "Персонажа"
- При убийстве монстров персонаж получает опыт
- При накоплении определенного количества опыта необходимого для повышения уровня, персонаж переходит на следующий уровень и получает некоторое количество характеристик и очков параметров
- Уровни персонажа ограничены с 0 до 50 уровня
- При достижении 50 уровня, у персонажа открывается система совершенствования  "Парагон", позволяющая дальнейшее повышение уровней персонажа с целью получения очков, которые можно вкладывать в характеристики
- Каждый уровень "Парагона" берется более долгим накоплением опыта при убийстве монстров
- Лимит уровней "Парагона" увеличивается с каждый крупным обновлением
- Набор ранее доступных уровней в последующих обновлениях, становиться проще, для того чтобы новые игроки не сильно отставали от старых игроков

Ориентировочное время прокачки до капа разных игровых уровней:
- Уровень персонажа: 0-50 Уровни должны достигаться путем фарма спотов, за время примерное 6 месяцев игры по 2-3 часа фарма в день. Первые 45 должны достигаться примерно за 1 месяц игры при тех же условиях. На этом уровне открывается весь возможный контент.
- Уровень владения отдельным оружием: 0-50. Уровни должны достигаться путем фарма спотов, за время примерно равное 3 месяцем игры по 2-3 часа в день.
- Уровень прокачки профессии: 0-50 Уровни должны получаться путем занятием данным ремеслом. Время прокачки одной профессии до макс уровня, за время примерно равное 3 месяцем игры по 2-3 часа в день.
