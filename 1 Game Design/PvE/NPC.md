Не игровые персонажа, размещаются в мире для наполнения, взаимодейтсвия с ними. С ними можно общаться, с некоторыми торговать, некоторые выдают задания. 

Типы НПС:
- Сюжетные (сюжетные и второстепенные квесты)
- Торговцы (скупка и продажа различных предметов)
- Трактирщики (продают информацию в таверне)
- Убийцы (для ПвП контента убийц игроков)
- Охотники (для ПвП контента охоты на преступников)
- Капитаны стражи (продажа трофеев и повторяемые квесты)
- Фоновые (нет взаимодействий)
- Аукционист (аукцион)
- Распорядитель (аренда особняков и территорий для гильдий)

Диалоги и реплики
- При приближении к НПС - он произносит случайную фразу на подобии как это реализовано в Скайрим
- При взаимодействие с НПС открывается окно диалога, с помощью которого можно пообщаться с НПС
- У каждого НПС свой набор возможных уникальных диалогов
- Уникальный диалог начинается с фразы игрока, затем идет ответ НПС, после чего последующие варианты реплик
ветвятся, для текущего уникального диалога, по окончанию диалога возвращается стартовое окно диалог, а диалог 
помечается серым цветом, как уже проговоренный.
- Под диалогом подразумевается полный диалог с 1-й по последнюю реплику. Соответсвенно условия завершения диалога - окончание последней реплики. 

Торговля
- При нажатии кнопки "Торговать" в диалоге, открывается окно торговли
- Каждый НПС торговец торгует только своим ассортиментом товаром
- Торговля это отдельная реплика, у которой по нажатию открывается виджет торговли

Квесты
- В окне диалога с НПС, если у него есть доступные квесты для взятия, разговора по квесту или завершению, появляется соответсвующая кнопка диалога
- Квесты для взятия появляются при выполнение условий: они ранее не выполнены, они не активны, выполнены требования по ранее завершенным квестам и уровню персонажа
- Опции для прогресса в квесте (например по квесту надо поговорить с 3-мя разными НПС), появляются при наличии этого квеста и не выполненном условии в прогрессе квеста.
