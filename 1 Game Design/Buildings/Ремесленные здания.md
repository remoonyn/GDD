Ремесленные здания

В ремесленых зданиях осуществляется переработка ресурсов и крафт новых предметов. 
Глобально всего 5 зданий для крафта:
- Кузница
- Арканум
- Мастреская
- Алхимичкая лаборатория
- Кухня

В каждом из зданий есть свои отдельные производства:
- Кузница
	1. Переплавка руды в слитки или в изделия
	2. Изготовление древесного угля
	3. Изготовление оружия, брони, украшений
	4. Изготовление предметов улучшения качества
	5. Изготовления предметов для починки экипировки
- Арканум 
	1. Изготовление камней зачарований
	2. Изготовление камней улучшений / вознесения
	3. Изготовление гемов 
	4. Накладывание зачарований с помощью камней зачаровний
- Мастерская
	1.  Переработка дерева
	2. Выделка кожи
	3. Огранка драгоценных камней
	4. Обработка камня
	5. Изготовление мебели
- Алхимическая лаборатория
	1. Трасмутация ингридиентов
	2. Изготовление зелий
	3. Изготовление ядов, смазок (для оружия) 
	4. Изготовление материалов для кузнеца/зачарователя
	5. Изготовление удобрений
- Кухня 
	1. Заготовка ингридиентов
	2. Готовка еды боевой
	3. Готовка еды ремесленной
	4. Готовка еды для рабочих
	5. Готовка кормов для животных
