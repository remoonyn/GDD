Склад:
- Место хранения любых предметов игрока
- Склад разделен по категориям предметов
	1. Сундук (любые предметы)
	2. Стойки (оружие/броня/украшения)
	3. Шкатулка (гемы)
	4. Ресурсы (дерево, руды, растения, ингриденты, еда, блюда, зелья)
	5. Расходные (порошки)
- Игрок может открывать новые категории и увеличивать их вместимость с помощью улучшения складов

Reference: Path of Exile с их вкладками сундука
