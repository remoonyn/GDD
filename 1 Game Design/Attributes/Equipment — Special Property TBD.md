- Получаются различными игровыми способами
- При получении "уникального свойства"  базовая эффективность свойства - 20%
- Базовую эффективность можно увеличить до 100% путем вкладывания в свойство крафтовых предметов
- Предмет при вкладывании исчезает и дает определённый % опыта свойства
- Свойство добавляется на предмет с помощью специального предмета (крафтового) на верстаке профессии "Зачарование"
- На каждом предмете экипировки могут быть свои свойства от 0 до 2 в зависимости от грейда, см 
- Одно и тоже свойство может быть только на 1 предмете экипировки. На доспехе и в кольце не может быть одновременно +250 ХП в качестве свойства.
- Свойство можно снять на специальном верстаке с помощью специальных игровых предметов (пример: "Пыль зачарования")
- Количество расходуемых предметов зависит от нескольких факторов: тип свойства, его уровень и в будущем придумать еще что-то
- Свойство можно заменить другим с помощью того же предмета
- Некоторые уникальные свойства возможно применить только на конкретном типе предмета (кольца, шлемы или что-то другое)
