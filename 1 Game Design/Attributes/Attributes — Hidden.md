Значения скрытых атрибутов нигде не указывается виджетах, игрок не может их каким либо образом увидеть нигде, кроме кода игры. Они носят исключительно технический характер для расчетов в игровых механиках

Скрытые атрибуты
- Коэфициент агрессии  -> [[Agression]]
- Эффективность блокирования -> [[Skill Defensive Effects]]
- Базовый урон реакции -> Combat
- Базовый урон статуса  -> Combat

Примечание:
- В виде исключения значение атрибута может указываться в подсказках при наведение на описание тех или иных игровых механиках
